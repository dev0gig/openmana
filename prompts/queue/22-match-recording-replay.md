# 22 — Automatic match recording and replay
Automatically record every started match to IndexedDB. Store OpenMana/engine/Forge versions, engine manifest hash, RNG seed where controllable, both deck lists, player inputs, Forge questions/answers, structured events and authoritative snapshots. Build a Matches library with result/turns/duration and step-by-step snapshot replay plus portable replay JSON export/import. Replay never acts on a live match. Add configurable retention (default latest 100), delete/clear and tests. Deterministic re-simulation is desirable where supported; snapshot replay is the reliable baseline.
